# Security policy

Report vulnerabilities privately through GitHub Security Advisories. Do not open a public issue with a secret or a wallet address.

In scope: the `crypto_intel` package, risk gate, audit log, anomaly detection, and CI tripwires.
Out of scope: live trading profit claims. This repository cannot place live orders.

Supported branch: `main`.

Version 0.10 expands StochRSI filters, cloud proxies, dynamic sizing, broader redaction, and multi-stat anomaly. See docs/security-architecture.md.
